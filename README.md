# Programação Web, 2026/2027

Materiais de apoio às aulas laboratoriais.

## Sobre este repositório

Este repositório destina-se **exclusivamente a apoiar as aulas laboratoriais das turmas de Programação Web que leciono no ano letivo 2026/2027**.

Os materiais aqui disponibilizados têm um caráter **complementar e de apoio**, podendo ser utilizados pelos alunos como referência durante as aulas laboratoriais, no estudo autónomo ou como auxílio à realização do trabalho prático.

> **Este repositório não constitui uma fonte oficial de materiais da unidade curricular e não substitui, em nenhuma circunstância, os conteúdos e informações disponibilizados no Moodle oficial de Programação Web.**

Os materiais aqui publicados são da minha responsabilidade enquanto docente das respetivas aulas laboratoriais e **não vinculam os restantes docentes da unidade curricular**.

O **Moodle oficial da unidade curricular é a fonte de referência** para materiais oficiais, informações, regras, prazos e demais indicações relativas ao funcionamento de Programação Web.

Por esse motivo, neste repositório **não serão disponibilizados**:

- formulários de inscrição;
- mecanismos ou formulários para submissão de trabalhos;
- informações oficiais sobre prazos ou avaliações;
- regras gerais de funcionamento da unidade curricular;
- outros documentos ou comunicações de caráter oficial.

Em caso de divergência entre qualquer informação ou material presente neste repositório e o disponibilizado através dos canais oficiais da unidade curricular, **prevalece sempre a informação disponibilizada no Moodle**.

## Como obter os materiais

Clonar o repositório para uma pasta local:

```bash
git clone https://github.com/goncalo-roseiro-isec/pweb-2026-2027.git
cd pweb-2026-2027
```

Em alternativa, sem utilizar Git: botão verde **Code**, opção **Download ZIP**.

Para atualizar posteriormente o repositório com novos materiais publicados:

```bash
git pull
```
