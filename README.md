## Como obter os materiais

Clonar o repositório para uma pasta local:

```bash
git clone https://github.com/goncalo-roseiro-isec/pweb-2026-2027.git
cd pweb-2026-2027
```

Em alternativa, sem usar o Git: botão verde **Code**, opção **Download ZIP**.

Para atualizar mais tarde, com novos materiais publicados:

```bash
git pull
```
